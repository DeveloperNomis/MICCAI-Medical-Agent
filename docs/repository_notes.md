# Repository notes

This repository is a cleaned research-code release for the MICCAI Agent Workshop submission.

The repository intentionally excludes:

- medical image data,
- segmentation masks,
- trained model checkpoints,
- generated predictions,
- experiment logs,
- cluster-specific Slurm scripts,
- exploratory hyperparameter files not used in the final configuration.

The goal is to provide the final implementation, expected data formats, and reproducibility instructions without including private data or environment-specific files.
